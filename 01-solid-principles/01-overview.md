# SOLID Principles — Overview

SOLID is a set of five object-oriented design principles that help make software easier to maintain, extend, test, and understand.

## The Five Principles

| Principle | Meaning |
|---|---|
| SRP | Single Responsibility Principle |
| OCP | Open/Closed Principle |
| LSP | Liskov Substitution Principle |
| ISP | Interface Segregation Principle |
| DIP | Dependency Inversion Principle |

## Why SOLID Matters

Poorly designed software often develops:

- High coupling
- Low cohesion
- Difficult-to-test code
- Large classes
- Fragile changes
- Duplicated logic
- Difficult extensions

SOLID provides guidelines for avoiding these problems.

## Important

SOLID principles are guidelines, not rigid rules. Applying them blindly can create unnecessary abstractions and complexity.

The goal is to improve the design where there is a real problem.
